# 潮生 · TIDAL CITY

基于**单文件自包含 HTML**的海绵城市雨洪模拟可视化交互作品。无需服务器、无外部依赖，双击即可在浏览器离线打开。

> 参赛方向：2026 第一届 AIGC 与可视化创作大赛 · 赛道 5「互动可视化」

## 核心能力

- **1 分钟过程雨洪模型**：以 1 min 为步长模拟整场降雨，输出径流过程线（产流 → 蓄滞 → 溢流 → 退水）。
- **设计暴雨 / 重现期预设**：日常、2 年一遇、5 年一遇、50 年一遇四档，一键设置雨强与历时，并实时显示“当前强度约等于 X 年一遇”。
- **过程线播放**：过程线卡片支持 ▶ 自动播放整场降雨—径流—退水过程，并可悬停读取任意时刻读数。
- **设施滞蓄分解**：地下调蓄池、雨水花园、透水铺装等设施的滞蓄贡献占比可视化。
- **海绵成效评估**：依据留蓄率、削峰率与溢流情况，动态给出 S / A / B / C 四级评价结论。
- **数据导出**：过程线可导出 CSV，实验参数可导出 JSON 记录。

## 模型口径（简要）

- 研究区：12 ha 城市街区，综合径流系数约 0.9（传统对比情景）。
- 海绵设施调蓄总容积：18000 m³。
- 排水能力：按设计重现期对应的排放流量限值为基准。
- 计算边界：水量平衡（降雨 = 下渗滞蓄 + 外排 + 地表溢流），已对 960 组工况做数值一致性校验。
